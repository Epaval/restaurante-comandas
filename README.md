# 🍽️ Sistema de Gestión de Restaurante

Sistema completo de gestión de pedidos para restaurantes con roles de usuario (Mesero, Cocina, Caja, Entregas, Limpieza).

## 🚀 Características

- **Gestión de Mesas**: Visualización en tiempo real de disponibilidad
- **Flujo de Pedidos**: Desde la toma de pedido hasta el pago y limpieza
- **Roles de Usuario**: 
  - Administrador: Control total
  - Mesero: Toma de pedidos y gestión de mesas
  - Cocina: Visualización y preparación de pedidos
  - Caja: Procesamiento de pagos
  - Entregas: Gestión de pedidos listos
  - Limpieza: Gestión de limpieza de mesas
- **Panel de Limpieza**: Gestión de mesas en proceso de limpieza
- **Sistema de Pagos**: Registro de pagos y métodos de pago
- **Cancelación de Pedidos**: Cancelación con confirmación mediante modal moderno

## 🛠️ Tecnologías

- Django 6.1
- SQLite (desarrollo) / PostgreSQL (producción)
- HTML5, CSS3, JavaScript
- Bootstrap 5
- Font Awesome
